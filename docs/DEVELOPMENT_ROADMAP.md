# Capability-gated roadmap

| Stage | Question | Advance only with evidence |
|---|---|---|
| L.0 | Are consequences reproducible and meaningful? | Determinism, ledger, actions, termination, observation isolation, changing world, reproducible controls pass. |
| L.1 | Does one neural cell improve from actual interactions? | Remote persistence admission and independent unseen-world behavioral/prediction gates against all controls. |
| L.2 | Does the same learner adapt and retain? | Prior competence, changed rules, delayed retention and faster adaptation against history-matched controls without resets. |
| L.3 | Does a second cell help? | Learned communication/complementarity beats capacity-matched single cell including coordination costs; no assigned specialization claims. |
| L.4 | Can organization develop? | Reversible module allocation, differentiation/growth/pruning improve controlled outcomes while retaining prior competence. |
| L.5 | Can learning processes improve themselves? | Independently qualified experience selection/learning/topology proposals improve future acquisition at matched resources with rollback. |

L.0 is implemented and locally checked. L.1 executed: Learning FAIL (H1/H2 FAIL, H3 persistence PASS); see L1_QUALIFICATION.md.
L.2–L.5 are research hypotheses only. Implementation completion never opens the next
gate automatically. All architecture changes require finite envelopes and migration
invariants; no autonomous source modification, deployment or compute acquisition.
